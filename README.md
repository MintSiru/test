# ⚾ 청춘나인 — 한국 고교야구부 육성 시뮬레이션

> **본 게임은 비상업적 비공식 팬메이드 게임이며, 실존 선수·구단·KBO와 관련이 없습니다. 게임 속 성적과 사건은 모두 가상입니다.**

파워풀 프로야구의 **영관나인(栄冠ナイン)** 과 프로야구 스피리츠의 **백구의 기적(白球のキセキ)** 에서 영감을 받은,
한국 고교야구를 배경으로 한 2D 도트 그래픽 야구부 감독 시뮬레이션입니다.

- **실제 한국 고교야구 대회 일정** — 주말리그 전·후반기, 신세계 이마트배, 황금사자기, 청룡기, 대통령배, 봉황대기, 전국체전, KBO 신인 드래프트
- **인게임 관전과 작전 지시** — 공 하나하나를 도트 야구장에서 관전하며 번트·스퀴즈·도루·히트앤런·고의사구·전진수비·대타·대주자·투수교체를 지시
- **동경하는 프로 선수** — 성은 다르고 이름이 같은 프로 선수를 동경하는 고교 선수 (예: 김도영을 동경하는 박도영). 동경 선수의 장기를 닮아 가며 성장하고, 특별 이벤트가 일어난다. 프로 선수는 실명(2026 시즌 기준)이며 구단은 가상 — 새 게임에서 '가상 선수' 명단도 고를 수 있다
- **특수능력 85종** — 금특(노랑★)·긍정(파랑)·부정(빨강)으로 색 구분. 득점권·7회 이후·좌투수 상대 등 조건에 맞으면 발동하고, 경기 중 「발동」으로 보인다. 각성·동경 선수·장터로 부정 능력을 극복하고 금특으로 진화
- **야구부 포인트 · 장터** — 경기 결과로 포인트를 얻고, 매월 1~7일 열리는 장터에서 특수능력 교본·능력치 아이템·회복 아이템을 산다. 시설 기물은 방학·비시즌 달에만 설치
- **후원회 연간 목표** — 명성에 맞춘 올해 목표 3개. 달성하면 포인트·명성
- **처음 하는 사람을 위한 안내** — 처음 한 번 뜨는 안내와 화면마다 「?」 도움말, 특수능력 도감
- **저장 슬롯 3개 · 경기 중 저장** — 경기 도중 나가도 같은 이닝·점수·주자부터 이어서
- **작전 성공 가능성** — 도루·번트·스퀴즈·히트앤런 버튼에 상·중·하 표시, 특수능력 「발동!」 실황
- **비시즌** — 동계 합숙 장소 선택과 합숙 에피소드, 3학년 진로 상담(감독 추천서), 학교 행사. 지명받지 못한 졸업생은 대학·독립리그를 거쳐 4년 뒤 프로에 도전
- **기록실 · 명예의 전당** — 전국 개인 타이틀 7개, 학교 기록, 졸업생의 고교·프로 성적
- **포지션 연습 · 투타 겸업** — 부포지션을 새로 익히고, 잘 치는 투수는 선발 날 지명타자로
- **살아 있는 고교야구계** — 해마다 신흥 강호가 떠오르고 명문이 흔들린다
- **장터 행사** — 여름 대회 대비 특가, 연말 대바겐, 복주머니
- **주장 · 팀 분위기 · 감독 성장** — 이기면 분위기가 살고, 감독은 레벨이 오를 때마다 특기를 익힌다
- **명장면 · 업적 · 선수 이야기** — 끝내기·역전 적시타 앨범, 업적 24개와 특수능력 수집, 불방망이·슬럼프·재활 복귀
- **홈 화면 앱** — 휴대폰 홈 화면에 추가하면 주소창 없이, 두 번째부터는 인터넷 없이도 실행
- **휴대폰에서도** — 화면 크기에 맞춰 꽉 차게 (가로로 들면 더 크게), 안드로이드 전체 화면
- 그 밖에: 주간 훈련 카드, 3년 주기 입학·졸업·드래프트, 스카우트, 라이벌 학교, 날씨·우천 순연, 연습 경기, 마운드 방문·수비 교체, 박스스코어, 칩튠 BGM(득점권 찬스 응원가 포함)

## 플레이 방법

### 1) 브라우저에서 (설치 없음)
**https://mintsiru.github.io/test/** 에서 바로 플레이할 수 있습니다. (다른 저장소라면 `https://<계정>.github.io/<저장소>/`)
(저장소 **Settings → Pages → Source: GitHub Actions** 를 한 번 선택해 두면, 기본 브랜치에 푸시될 때마다 자동 배포됩니다.)

- `/` : 게임 (Godot 웹 빌드)
- `/foundation/` : 기반 시스템 확인용 화면 (텍스트 UI)

### 2) Godot 에디터에서
1. [Godot 4.7](https://godotengine.org/download) 을 설치합니다. (표준판, .NET 아님)
2. Godot 실행 → **가져오기(Import)** → 이 저장소의 `game/project.godot` 선택
3. **F5** (실행)

PC용 실행 파일이 필요하면 에디터의 **프로젝트 → 내보내기 → Windows** 를 쓰세요. (처음 한 번 “내보내기 템플릿 다운로드” 필요)

## 저장소 구조

```
game/   Godot 4.7 프로젝트 (실제 게임) — GDScript, 도트 그래픽은 코드로 생성
  data/       공용 데이터(JSON): 학교·권역, 프로 선수, 대회 일정, 특수능력, 장터, 후원회 목표, 도움말, 이름
  scripts/core  시즌·대회·훈련·동경·스카우트 로직
  scripts/sim   투구 단위 경기 엔진 + CPU 감독 AI
  scripts/ui    화면(타이틀/홈/선수단/오더/일정/스카우트/기록/경기) + 도트 필드
  tests/        헤드리스 테스트 (밸런스·특수능력, 1년 시즌, 경기 중 저장, UI 흐름)
web/    기반 시스템 (TypeScript) — 규칙·밸런스를 빠르게 검증하는 원형. game/data 를 같이 읽는다
docs/   기획서(GDD)와 로드맵
tools/  웹 빌드 성능 측정 스크립트
```

## 개발 · 테스트

```bash
# 기반 시스템 (Node 22)
cd web && npm install && npm test          # 경기 밸런스 + 2시즌 시뮬레이션
npm run dev                                 # 텍스트 UI (http://localhost:5173)

# 게임 (Godot 4.7)
GODOT=/경로/godot game/tests/run_tests.sh   # 헤드리스: 밸런스 + 1년 시즌 + 경기 중 저장
node tools/web_bench.mjs build/web          # 웹 빌드 성능 측정 (헤드리스 Chromium, playwright 필요)
node tools/mobile_check.mjs build/web shots # 휴대폰 8개 기종 화면비율·터치·입력 점검
```

AI 로 개발을 이어갈 때 참고할 내용은 [`CLAUDE.md`](CLAUDE.md), 기획 전반은 [`docs/GDD.md`](docs/GDD.md), 다음 작업 계획은 [`docs/ROADMAP.md`](docs/ROADMAP.md) 에 있습니다.
