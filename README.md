# ⚾ 청춘나인 — 한국 고교야구부 육성 시뮬레이션

파워풀 프로야구의 **영관나인(栄冠ナイン)** 과 프로야구 스피리츠의 **백구의 기적(白球のキセキ)** 에서 영감을 받은,
한국 고교야구를 배경으로 한 2D 도트 그래픽 야구부 감독 시뮬레이션입니다.

- **실제 한국 고교야구 대회 일정** — 주말리그 전·후반기, 신세계 이마트배, 황금사자기, 청룡기, 대통령배, 봉황대기, 전국체전, KBO 신인 드래프트
- **인게임 관전과 작전 지시** — 공 하나하나를 도트 야구장에서 관전하며 번트·스퀴즈·도루·히트앤런·고의사구·전진수비·대타·대주자·투수교체를 지시
- **동경하는 프로 선수** — 성은 다르고 이름이 같은 프로 선수를 동경하는 고교 선수. 동경 선수의 장기를 닮아 가며 성장하고, 특별 이벤트가 일어난다

## 플레이 방법

### 1) 브라우저에서 (설치 없음)
GitHub Pages 를 켜면 `https://<계정>.github.io/<저장소>/` 에서 바로 플레이할 수 있습니다.
(저장소 **Settings → Pages → Source: GitHub Actions** 를 한 번 선택해 두면, 기본 브랜치에 푸시될 때마다 자동 배포됩니다.)

- `/` : 게임 (Godot 웹 빌드)
- `/foundation/` : 기반 시스템 확인용 화면 (텍스트 UI)

### 2) Godot 에디터에서
1. [Godot 4.7](https://godotengine.org/download) 을 설치합니다. (표준판, .NET 아님)
2. Godot 실행 → **가져오기(Import)** → 이 저장소의 `game/project.godot` 선택
3. **F5** (실행)

PC용 실행 파일이 필요하면 에디터의 **프로젝트 → 내보내기 → Windows** 를 쓰세요. (처음 한 번 “내보내기 템플릿 다운로드” 필요)

## 저장소 구조

```
game/   Godot 4.7 프로젝트 (실제 게임) — GDScript, 도트 그래픽은 코드로 생성
  data/       공용 데이터(JSON): 학교·권역, 가상 프로 리그, 대회 일정, 특수능력, 이름
  scripts/core  시즌·대회·훈련·동경·스카우트 로직
  scripts/sim   투구 단위 경기 엔진 + CPU 감독 AI
  scripts/ui    화면(타이틀/홈/선수단/오더/일정/스카우트/기록/경기) + 도트 필드
  tests/        헤드리스 테스트 (밸런스, 1년 시즌, UI 흐름)
web/    기반 시스템 (TypeScript) — 규칙·밸런스를 빠르게 검증하는 원형. game/data 를 같이 읽는다
docs/   기획서(GDD)와 로드맵
```

## 개발 · 테스트

```bash
# 기반 시스템 (Node 22)
cd web && npm install && npm test          # 경기 밸런스 + 2시즌 시뮬레이션
npm run dev                                 # 텍스트 UI (http://localhost:5173)

# 게임 (Godot 4.7)
GODOT=/경로/godot game/tests/run_tests.sh   # 헤드리스: 밸런스 + 1년 시즌
```

AI 로 개발을 이어갈 때 참고할 내용은 [`CLAUDE.md`](CLAUDE.md), 기획 전반은 [`docs/GDD.md`](docs/GDD.md) 에 있습니다.
