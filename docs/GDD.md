# 청춘나인 기획서 (GDD)

## 1. 개요

- **장르**: 고교 야구부 감독 육성 시뮬레이션 (영관나인 + 백구의 기적 계열)
- **배경**: 대한민국 고교야구. 실제 대회 일정을 따라 1년이 흐르고 3년 주기로 선수가 입학·졸업한다.
- **플랫폼**: Godot 4.7 (PC · 웹). 해상도 640×360 도트, 정수배 확대.
- **목표**: 전국 대회 우승, 프로 선수 배출. 끝이 없는 연속 플레이.

## 2. 필수 요소와 구현

### 2-1. 실제 한국 고교야구 대회 일정 (`game/data/schedule.json`)

2026 시즌 대한야구소프트볼협회 발표 일정을 기준으로 한다. 다음 해에는 **같은 날짜 근처의 같은 요일**로 자동 이동한다.

| 대회 | 2026 일정 | 참가 방식 (게임 구현) |
|---|---|---|
| 고교야구 주말리그 전반기 | 3/7 ~ 4/26 (토·일) | 15개 권역 풀리그 (전 팀) |
| 신세계 이마트배 | 3/25 ~ 4/13 | 전 팀 토너먼트 (주말리그와 겹치지 않게 평일 편성) |
| 제80회 황금사자기 | 5/2 ~ 5/16 | 전반기 권역 1위 + 짝수 순위 |
| 주말리그 후반기 | 5/23 ~ 6/21 | 15개 권역 풀리그 |
| 고교-대학 올스타전 | 6/8 | 소식 이벤트 |
| 제81회 청룡기 | 6/27 ~ 7/11 | 전반기 권역 1위 + 홀수 순위 |
| 제60회 대통령배 | 7/18 ~ 7/30 | 후반기 권역 상위 4팀 |
| 제54회 봉황대기 | 8/6 ~ 8/29 | 전 팀 토너먼트 |
| 전국체전 대표 선발 | 9/1 | 시·도별 시즌 포인트 1위 |
| KBO 신인 드래프트 | 9/21 | 전국 3학년 중 상위 70명 지명 (11라운드) |
| 제107회 전국체육대회 | 10/16 ~ 10/22 | 시·도 대표 토너먼트 |

- 전반기 권역 1위는 황금사자기·청룡기 동시 출전 (실제 규정), 나머지 순위를 홀짝으로 나누는 방식도 실제 운영을 따랐다.
  어느 쪽이 짝수인지는 공개 자료로 확인하지 못해 **짝수 → 황금사자기, 홀수 → 청룡기**로 정했다.
- 경기 규칙: 9이닝, 지명타자, 콜드게임(5회 10점·7회 7점), 10회부터 무사 1·2루 승부치기, 1경기 최대 105구,
  **투구수별 의무 휴식** (31~45구 1일, 46~60구 2일, 61~75구 3일, 76구 이상 4일).
- 출처: 뉴스그라운드 「주말리그부터 올스타전까지... 2026년도 고교야구 대회 일정」, 더리더스 「2026 제81회 청룡기 27일 개막」, KBO 2027 신인 드래프트 보도.

### 2-2. 인게임 관전과 작전 지시 (`scripts/sim/match_engine.gd`, `scripts/ui/screens/match_screen.gd`)

- **투구 단위 엔진**: 공 하나마다 구종·구속·코스(스트라이크존) → 스윙 판단 → 컨택 → 타구(땅볼/라이너/플라이/팝업, 방향·비거리) → 수비·주루 판정.
- **관전 화면**: 부감 시점 도트 야구장. 투구 궤적, 타구 비행(그림자와 높이), 야수 이동, 주자 진루, 스트라이크존 인셋, 전광판.
- **지시 타이밍**: 매 투구 / 타석마다(기본) / 찬스·위기만 / 멈추지 않음. 속도 ×1·×2·×4·결과만. 언제든 위임 가능.
- **공격 작전**: 자유 타격, 기다려, 적극 공략, 희생 번트, 기습 번트, 스퀴즈, 도루, 히트앤런, 대타, 대주자
- **수비 작전**: 자유 투구, 정면 승부, 유인구 위주, 고의사구 / 기본·전진·번트 시프트·장타 경계 / 투수 교체
- **CPU 감독 AI** (`match_ai.gd`): 상황별 번트·스퀴즈·도루, 고의사구, 전진수비, 투구수·피로·실점에 따른 투수 교체.
- **밸런스 목표**(고교 나무배트): 팀당 타율 .270~.290, 경기당 4~5점, 홈런 0.1~0.2개, 삼진 17%, 볼넷 9%. 테스트로 고정.

### 2-3. 동경하는 프로 선수 (`scripts/core/idol.gd`, `data/pros.json`)

- 신입생·유망주의 약 22~30%가 프로 선수 한 명을 동경한다. **이름(given name)은 같고 성은 다르다.** (예: 프로 `강도윤` ↔ 고교생 `박도윤`)
- 프로 선수는 스타일을 가진다: 파워히터, 교타자, 준족, 강견, 명수비, 클러치, 파이어볼러, 제구파, 변화구, 철완.
  투수는 투수를, 야수는 야수를 동경한다.
- **효과**
  - 동경 선수 스타일의 능력치 성장 ×1.25 (동경도 50 이상 ×1.4)
  - 프로 시즌(4~10월) 주간 프로야구 소식 → 동경도 +3~7, 컨디션 상승
  - 경기에서 활약(멀티히트·홈런·호투) → 동경도 +2
  - **동경도 70 「동경의 비결」**: 동경 선수의 대표 특수능력 습득
  - **동경도 100 「꿈의 만남」**: 프로 선수와 만남, 스타일 능력치 +5·한계 상승, 절호조
  - **드래프트**: 동경 선수와 같은 구단에 지명되면 특별 메시지
  - 우리 학교 졸업생이 프로가 되면 가상 리그에 추가되고, **그 OB를 동경하는 중학생은 스카우트 의향이 높다**.
- v0.3부터 프로 선수는 **실명**(2026 시즌 기준 68명, `data/pros.json`)을 비상업적 비공식 팬메이드로 사용한다. 구단명은 가상(연고지 대응)이며
  타이틀·새 게임 화면·README 에 「본 게임은 비상업적 비공식 팬메이드 게임이며, 실존 선수·구단·KBO와 관련이 없습니다」 고지를 둔다.
  새 게임에서 가상 명단(`data/pros_fictional.json`)을 고를 수 있다.

  - 검증(5년, 3시드 평균): 장터를 쓰면 팀 전력 53.3 → 59.3, 전국 순위 3.0위 → 1.3위. 연간 획득 700~1300P.

- **훈련 카드 순환**: 4주 동안 쓰지 않은 카드는 새 카드로 바뀐다.
- **프로 리그 순환**: 매년 전국 상위 지명자 10명 + 우리 학교 지명자가 프로에 합류, 아무도 동경하지 않는 은퇴 선수는 정리.

  지명 못 받은 3학년은 전국 예상 순위에 따라 대학(300위 안 또는 50%)·독립리그. 4년 뒤 대졸 드래프트 확률 150위 안 35% · 300위 안 15% · 그 밖 4% (독립리그는 절반).

## 4. 수치 설계 요약

- 능력치 1~100 (구속은 km/h). 등급 S(90)·A(80)·B(70)·C(60)·D(50)·E(40)·F(20)·G.
- 성장: 경험치 누적 → 1포인트 비용 = 2.2 + (현재/한계)² × 4. 재능·성격·동경·피로·컨디션 배율.
- 입학 선수 품질: CPU 팀은 전통(prestige), 우리 팀은 명성(reputation)과 스카우트로 결정.
- 명성: 대회 성적·드래프트로 상승, 매년 20 쪽으로 조금씩 회귀.

## 5. 기술 구조

- `web/` (TypeScript): 규칙의 **원형**. 빠른 밸런스 실험·테스트용. 결과를 Godot 로 이식한다.
- `game/` (GDScript): 실제 게임. 로직은 웹과 **같은 데이터 구조(Dictionary = JSON)** 로 1:1 대응.
- `game/data/*.json`: 두 쪽이 함께 읽는 단일 데이터 원본.
- 세이브: 슬롯 3개 `user://save_N.json` (웹 빌드는 브라우저 저장소). 압축 바이너리 약 0.85MB (이름은 .json 이지만 내용은 Godot 바이너리). 경기 중이면 입력 기록 포함.
- 동등성: 난수를 쓰지 않는 규칙 함수는 `game/tests/parity.json` 기준값으로 웹·Godot 가 같은 값을 내는지 검사.
- 도트 그래픽은 코드로 생성(PixelArt): 얼굴 24×24, 필드 선수 8×12, 구장 배경은 픽셀 단위 렌더링 후 캐시.
