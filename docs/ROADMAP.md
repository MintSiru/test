# 로드맵

> 작성 원칙: 각 항목에 **왜 필요한지(근거)** 와 **끝났다고 판단하는 기준(검증)** 을 적는다.
> 근거는 가능한 한 테스트·측정 결과에서 가져온다.

## 0. v0.3 변경 (사용자 요청)

| 요청 | 반영 | 검증 |
|---|---|---|
| 시설·예산을 원작식 포인트·상점으로 | 경기 결과 → 야구부 포인트, 매월 1~7일 장터(33종 중 7종 무작위), 특수능력 교본·능력치 아이템·회복 아이템, 시설 기물은 방학·비시즌 달에만 | TS·Godot 단위 테스트, 5년 3시드: 전력 53.3 → 59.3 |
| 프로 선수 실명 사용 | 2026 시즌 기준 68명(올스타·FA 이적 반영), 구단은 가상, 가상 명단 선택 가능 | 테스트: 실명·가상 명단 |
| 팬메이드 고지 | 타이틀·새 게임·README·웹 확인 화면 | 스크린샷 |

발견해 고친 문제: 7월에도 시설 기물을 설치할 수 없던 버그 (JSON 숫자가 float 라 `7 in [7.0]` 이 false). 그 전 테스트는 "3월에는 설치 불가"만 확인해서 우연히 통과하고 있었다 → 7월 설치 성공 테스트 추가.
원래 로드맵 항목 "시설 투자·예산"은 이 방식으로 대체했다.

## 1. 지난 라운드 결과 (v0.2)

이전 로드맵 7개 항목을 모두 진행했다.

| 이전 항목 | 결과 | 검증 |
|---|---|---|
| 효과음·BGM | 효과음 5종 + 칩튠 BGM 2곡(메뉴 16초·경기 13초 루프)을 코드로 합성 | 생성 0.25초, 클리핑 0 |
| 경기 중 수비 교체·마운드 방문 | 수비 교체 UI, 마운드 방문(경기당 3회, 다음 두 타자 제구 +8), CPU도 위기 때 사용 | UI 통합 테스트 |
| 상대 전력 분석·라이벌 | 라이벌 학교(같은 권역 최강 → 2패 이상 당한 학교로 교체), 라이벌전 투지, 상대 전적, 팀 타율·ERA 분석 | 시즌 테스트 |
| 시설 투자·예산 | 후원금·격려금·OB 기부, 시설 6종 Lv0~3 | 5년 시뮬레이션: 시설 투자 시 전국 1위 도달 **1년 단축** |
| 시뮬레이션 속도 | 1년 21.3초 → **17.5초**, 주말 50경기도 화면이 멈추지 않게 프레임 분할 | tests/bench.gd |
| 날씨·야간 경기 | 맑음/흐림/가랑비/비, 우천 순연, 8강 이후 야간 조명 | 연기율 테스트 |
| 얼굴·터치 | 턱·안경·점 추가, 특수능력 눌러서 설명 보기 | 얼굴 36장 시트 확인 |

추가로 넣은 것: 훈련 성과 표시, 박스스코어, 연습 경기(비시즌), 훈련 카드 순환, 전 시즌 UI 자동 플레이 테스트.

## 2. 개발·테스트 중 발견해 고친 문제

| 발견 | 어떻게 찾았나 | 조치 |
|---|---|---|
| 비가 며칠씩 이어져 경기 35.6% 연기, 308경기가 두 번 연기 | 연기율 측정 | 날씨 해시에 섞기 함수 추가(웹·Godot 같은 값 검증), 강수 확률 하향 → 이틀 연속 연기 5~34경기 |
| 10년쯤 지나면 초기 프로 선수가 은퇴해 **동경 시스템이 약해짐** | 코드 검토 → 10년 테스트 | 매년 다른 학교 상위 지명자 10명도 프로 합류 → 10년 뒤 현역 139명, 동경 선수 421명 |
| 훈련 손패가 숫자 1 카드로 굳음 | 전 시즌 UI 자동 플레이 스크린샷 | 4주 안 쓴 카드 자동 교체 |
| 장마철 소식창이 우천 연기 소식으로 도배 | 같은 스크린샷 | 우리 경기 연기만 소식으로 |
| 시설 효과가 체감되지 않음 (전력 58.9 vs 59.1) | 5년 비교 시뮬레이션 | 시설 +20%/Lv, 기본 성장 10% 하향 |
| 10~2월에 할 일이 훈련뿐 | 전 시즌 UI 자동 플레이 | 연습 경기 추가 (P2에 비시즌 콘텐츠 남음) |
| 스카우트 방문 버튼 잘림, 경기 준비 화면 글자 넘침 | 스크린샷 검토 | 레이아웃 수정 |
| GDScript 스레드 병렬화가 빨라지지 않음 (릴리스 빌드 포함) | 벤치마크 | 도입하지 않음 (CLAUDE.md 기록) |
| 스크립트 파스 오류가 있으면 테스트가 멈춘 것처럼 보임 | 개발 중 반복 | `--check-only` 파스 검사를 테스트 첫 단계로 |

## 3. 새 로드맵

### P1 — 다음 라운드

1. **튜토리얼·도움말**
   - 근거: 시스템이 많아졌다(카드·포인트·장터·스카우트·동경·투구수 규정·라이벌·날씨). 처음 하는 사람이 알아낼 방법이 없다.
   - 내용: 첫 주·첫 경기·첫 드래프트 때 안내 팝업, 화면마다 「?」 도움말.
   - 검증: UI 테스트에서 새 게임 첫 주에 안내가 뜨고 다시는 안 뜨는지.
2. **연간 목표 (후원회 목표)**
   - 근거: 자동 플레이 1년 차에 전국대회는 대부분 1회전 탈락. 약체 시기에 이룰 수 있는 목표가 없다.
   - 내용: 명성에 맞춘 목표(예: 주말리그 3위 이내, 전국대회 1승, 프로 지명 1명)와 포인트 보상.
   - 검증: 5년 시뮬레이션에서 1년 차 목표 달성률 40~70%.
3. **세이브 슬롯 3개 + 경기 중 저장**
   - 근거: 지금은 슬롯 1개이고, 경기 도중 종료하면 그 경기를 처음부터 다시 한다.
   - 검증: 경기 중 저장 → 불러오기 → 같은 이닝·점수·주자에서 재개하는 UI 테스트.
4. **웹 빌드 성능 측정·개선**
   - 근거: 데스크톱은 1년 17.5초지만 웹(WASM)은 측정하지 못했다. 경기 1개에 약 13ms가 들고, 대부분은 투구 처리다.
   - 내용: 브라우저 자동 측정 스크립트. 필요하면 CPU끼리 경기를 타석 단위 약식 계산으로 바꾼다(밸런스 테스트로 분포가 같은지 확인).
   - 검증: 웹에서 경기 많은 주말 하루 진행이 1초 이하.

### P2

- **장터 확장**: 특정 시기 한정 상품(여름 대회 전 스태미나 보강, 연말 대바겐), 가방 아이템 일괄 사용
- **프로 명단 연 1회 갱신 가이드**: 실명 명단(`pros.json`)은 이적·은퇴가 잦으니 시즌마다 갱신 절차를 CLAUDE.md 에 정리

5. **비시즌 콘텐츠**
   - 근거: 10~2월에는 연습 경기·스카우트만 있다.
   - 내용: 동계 합숙 장소 선택(비용·효과), 학교 행사 이벤트, 3학년 진로 상담.
6. **기록·명예의 전당**
   - 내용: 시즌 개인 타이틀(타율·홈런·다승), 졸업생 프로 성적 추적, 학교 역대 기록.
7. **포지션 컨버전·투타 겸업**
   - 근거: 오더 화면에서 「적성↓」가 자주 보인다. 야수가 부족한 해가 있다.
8. **작전 성공 확률 안내**
   - 내용: 도루·번트·스퀴즈 버튼에 대략적인 성공률(상·중·하)을 표시해 초보자도 판단할 수 있게 한다.
9. **CPU 학교 흥망**
   - 근거: CPU 학교 전력은 전통 수치로만 정해져 순위 변동이 적다.
   - 내용: 신흥 강호, 명문 몰락 이벤트, CPU 시설 투자.

### P3

    - 근거: 폰트 TTF 약 12MB.
    - 내용: 한글 서브셋, 로딩 화면.
11. **응원가·BGM 추가**
    - 내용: 학교별 응원가, 결승전 전용 곡.
12. **모바일 큰 글씨 모드**
    - 근거: 640×360 기준 버튼 높이가 16px.
13. **웹 기반 시스템 ↔ Godot 동등성 검사 강화**
    - 근거: 난수 방식이 달라 같은 시드로도 결과가 다르다.
    - 내용: 날씨 해시처럼 결정적인 부분은 값 일치 테스트, 나머지는 통계 분포 비교 테스트로 확인.
