## 1. 개발·테스트 중 발견해 고친 문제

| 발견 | 어떻게 찾았나 | 조치 |
|---|---|---|
| 모바일에서 게임이 작게 보임 | 기종별 자동 스크린샷 | 소수 배율 전환 |
| 빠른 경로(CPU끼리 경기)에 3볼 0스트라이크 「기다려」가 빠짐 | 코드 비교 | 추가 |
| 빠른 경로·일반 경로 통계 비교와 특수능력 효과 테스트가 가끔 실패 | 반복 실행 | 매번 다른 팀을 뽑아 비교하던 것을 같은 팀·다른 경기 운으로 비교 (같은 팀이면 차이 0.1%p 안) |
| 작전 확률 검증에서 번트 성공률이 100% 로 나옴 | 새 검증 테스트 | 테스트가 같은 투수로 수천 구를 던지게 해 투수가 지쳐 있었음 → 매 시도 투구수 초기화. 뜬 번트를 시도에서 빠뜨린 것도 수정 |
| 진로 상담에서 약체 팀은 추천서를 쓸 선수가 없음 | 스크린샷 | 예상 순위를 보여 주고 상위 3명에게 항상 선택지 |

## 2. 새 로드맵

### P1 — 다음 라운드

1. **모바일 조작감**
   - 근거: 휴대폰 가로에서 12px 글자가 약 11px(화면 기준)로 작고, 버튼 높이 16px 는 손가락으로 누르기 어렵다.
   - 내용: 큰 글씨·큰 버튼 모드(모바일에서 자동), 경기 화면 작전 버튼 확대, 길게 눌러 설명 보기.
   - 검증: `mobile_check` 로 주요 화면 스크린샷, 버튼 최소 크기(화면 기준 36px 이상) 검사.
2. **휴대폰 성능 2단계**
   - 근거: CPU 4배 제한에서 경기 많은 날 2.4초, 월요일 주간 처리(전국 선수 훈련) 83ms × 4배.
   - 내용: CPU 선수 주간 훈련을 한 번에 계산(팀 단위), 선수 변환 결과 재사용, 경기 많은 날은 진행 막대 표시.
   - 검증: CPU 4배 제한에서 경기 많은 날 1.5초 이하, 시즌 테스트 결과 분포 동일.
3. **기록·명예의 전당**
   - 내용: 시즌 개인 타이틀(타율·홈런·다승), 졸업생 프로 성적 추적, 학교 역대 기록.
4. **포지션 컨버전·투타 겸업**
   - 근거: 오더 화면에서 「적성↓」가 자주 보이고, 야수가 부족한 해가 있다.

### P2

5. **CPU 학교 흥망**: 신흥 강호, 명문 몰락, CPU 시설 투자
6. **장터 확장**: 시기 한정 상품(여름 대회 전, 연말 대바겐), 가방 일괄 사용
7. **세이브 크기 줄이기**: 2MB, 저장 문자열 변환이 CPU 4배 제한에서 0.77초
8. **비시즌 콘텐츠 확장**: 합숙 중 미니 이벤트, 진로 상담 결과(대학 진학 후 소식)
9. **프로 명단 연 1회 갱신 가이드** (`pros.json`)

### P3

10. **웹 첫 로딩 경량화**: 폰트 TTF 약 12MB → 한글 서브셋, 로딩 화면
11. **응원가·BGM 추가**
12. **웹 기반 시스템 ↔ Godot 동등성 검사 강화**
